# Eklabya Admin Client

Modern React + Vite + Tailwind CSS Admin Dashboard for Eklabya Platform.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```
   The application runs on `http://localhost:5174`.

3. Build for production:
   ```bash
   npm run build
   ```
